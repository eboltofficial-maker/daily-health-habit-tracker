# Daily Health Habit Tracker

A beginner-friendly, mobile-responsive wellness checklist built with plain HTML, CSS, and JavaScript.

## What it does
- Lets users check off five simple daily wellness habits.
- Shows a live completion count and progress bar.
- Saves today's checklist in the browser using `localStorage`.
- Resets automatically for a new date.
- Works without an account, server, or external library.

## Run it
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Tick habits as you complete them.

## Privacy
Checklist data stays in the user's browser on their device. The project does not send data to a server.

## Project reach and intended impact
This is a small open-source educational project designed to make preventive wellness habits easier to remember and track. It can be used by individuals, students, families, and community health educators as a simple demonstration of digital health promotion. It is intentionally lightweight so beginners can run, understand, translate, and improve it.

This project has not been clinically validated, and it does not diagnose, monitor, or treat any medical condition. It is not a substitute for professional medical advice.
